# CI signing keystore

`debug.keystore` here is **not a secret** — it uses the Android Gradle Plugin's
standard debug credentials (storePassword/keyPassword `android`, alias
`androiddebugkey`), the same ones `android/app/build.gradle` (generated by
`expo prebuild`, gitignored) hardcodes for both its `debug` and `release`
signing configs. That's intentional: this app has no Play Store release key,
so "release" builds are debug-signed, matching what a local
`expo prebuild && ./gradlew assembleRelease` already produces (see the
README's "Run it" section).

`android/` is regenerated fresh by `expo prebuild` every build (it's
gitignored), which means a release key living only inside it would differ on
every machine and every CI run — any two such builds couldn't update one
another. This file exists so CI always copies the *same* keystore into
`android/app/debug.keystore` before building, so every GitHub Actions release
is signed identically and able to upgrade the last one in place.

If you ever reinstall RUNbutan from an APK built before this file existed
(i.e. with a local, machine-specific debug keystore), Android will refuse to
install over it — uninstall the old copy once, and every build from here on
installs over the last.
